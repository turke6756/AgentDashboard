# Xenova/all-MiniLM-L6-v2

This directory contains the quantized ONNX form of `sentence-transformers/all-MiniLM-L6-v2`
published by Xenova for offline feature extraction. Lares uses only the Transformers.js web
build and its WASM backend; remote model loading is disabled.

The model produces 384-dimensional sentence embeddings. The upstream model and tokenizer are
licensed under the Apache License 2.0. See <https://huggingface.co/Xenova/all-MiniLM-L6-v2>
and <https://www.apache.org/licenses/LICENSE-2.0>.
